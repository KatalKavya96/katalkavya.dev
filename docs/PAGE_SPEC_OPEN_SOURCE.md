# Page Spec — Open Source

Reference: `references/03-open-source-reference.png`

## Identity

This page should communicate contribution, progression and collaboration.

Distinct hero background: cinematic mountain ridge / trail at dusk with subtle illuminated path or connected points.
It must not look like the Home planet.

## Hero

Eyebrow: `Open Source`
Headline options:

- `Building in public.`
- `Open Source Journey`

Prefer the shorter headline if it fits the composition.

Supporting copy: contribution to real-world open-source systems, adapters, integrations and developer infrastructure.

Primary CTA: `View contributions`
Secondary CTA: `GitHub`

### Floating evidence

Max four proof chips; use real organizations/contributions only.
Each chip should contain only organization/project + short contribution type/status.

## Metric strip

Omit this and the timeline until contribution links and dates are confirmed by Kavya.

Max four verified metrics such as:

- merged/open PRs or total meaningful PRs,
- organizations,
- repositories contributed to,
- active technical areas.

Avoid vanity metrics that do not help evaluate engineering work.

## Featured contributions

Three large contribution cards maximum on initial viewport/section.
A card should show:

- project/org,
- contribution title,
- one-line impact,
- status,
- relevant tech/domain,
- link to PR or repository.

Diff stats are optional and only if sourced reliably.

## Contribution timeline

Show six repository cards by default and offer access to the remaining repositories. Each card shows the latest raised PR. Hover or keyboard focus opens a scrollable newest-first timeline of authored PRs with open, merged, or closed status; click pins it open for inspection. Links lead directly to each PR. Mobile uses tap to open and pin.

## Organizations

Use an automatically updating, slowly panning ribbon of verified organization owners from the authored PR feed. Each organization appears once in the track, even when the feed refreshes. Keep the label in a separate fixed-width column so moving names never pass beneath it. Pan only when the list exceeds the available width; pause on hover or keyboard focus and stop under reduced-motion preference.

## Background floating PR idea

Allowed only as very low-opacity, slow, decorative context below/behind content.

- No more than 4–6 visible labels at once.
- They must never compromise readability.
- Disable or greatly simplify on mobile/reduced motion.

## Mobile

- Use a cropped mountain/trail hero.
- Float only one proof chip or none.
- Contribution cards stack.
- Timeline becomes vertical.
