# Page Spec — Home

Reference: `references/01-home-reference.png`

## Goal

Communicate identity, primary career direction and three strongest proof points in a single relaxed scroll.

## Hero

Headline: `Kavya Katal`

Career line will be added after Kavya confirms a preferred title and technical focus. The design preview uses a neutral statement about making useful systems.

Supporting sentence: one concise, verified statement about the work.

Primary CTA: `View my work`
Secondary CTA: `About me` until a GitHub or resume URL is confirmed.

### Right-side visual

Keep the cosmic/network sphere concept on Home only.
Floating proof chips: max four, selected from Kavya's verified work. In development, generic navigation chips may demonstrate the layout and must be labeled as samples.

Do not crowd the sphere with many labels.

## Role lens / "Explore my work as"

Optional compact role pills may be introduced after Kavya confirms relevant role language.

These may reorder/emphasize content, but the site must remain fully understandable without using them.

## Capability strip

Use navigation themes until Kavya's technical categories are confirmed: Build, Contribute, Experiment, Practice.

## Selected work

Show six verified public projects in a three-column desktop grid and stacked mobile cards. The first row gives the immediate proof; further cards may continue below the viewport. Curation order comes from the private editor.

Use live-feeling project visuals, not generic abstract thumbnails.

## Proof strip

One quiet strip with verified values only. Max four numerical metrics plus one short principle/quote.
If metrics are not verified, omit the strip rather than inventing them.

## Mobile

- Text first, sphere becomes partial background or simplified visual.
- Floating chips reduced to 1–2.
- Role-lens pills horizontally scroll if retained.
- Selected projects stack.
