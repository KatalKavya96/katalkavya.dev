# SEO & Analytics

## Metadata

Every route should have:

- unique title,
- concise meta description,
- canonical URL,
- Open Graph/Twitter image,
- meaningful social title/description.

## Structured data

Use relevant schema.org JSON-LD where accurate:

- `Person`
- `WebSite`
- `CreativeWork` / `SoftwareSourceCode` for selected projects when useful

Do not fabricate employment, awards or affiliations for structured data.

## Project sharing

Project detail pages should have generated/curated OG cards using project name, category and one strong visual.

## Analytics

Use privacy-conscious analytics if enabled.
Track useful events only:

- project opened,
- case study opened,
- GitHub/PR external link clicked,
- resume clicked/downloaded,
- contact CTA clicked.

Do not implement invasive session replay by default.
