# Content Collection Prompt

Use this before replacing placeholders with real portfolio data.

---

Audit the portfolio content for anything that is currently placeholder, unverifiable or missing.

Read `docs/CONTENT_INVENTORY.md` and `docs/CONTENT_AND_DATA.md`.

Create a concise checklist grouped by:

- personal links/contact,
- projects,
- open-source contributions,
- coding profiles,
- media/demo assets,
- resume/achievements.

For each missing item, tell me exactly what value or URL I need to provide. Do not ask me for information already present and verified in the repository. Do not invent substitute values.

After I provide the data, normalize it into the typed content model and remove corresponding TODOs/placeholders.
